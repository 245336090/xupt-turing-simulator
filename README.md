# 西安邮电大学 计算机科学导论课程 图灵机模拟器

用于课程练习的图灵机模拟器。输入五字段状态转移规则，观察纸带、读写头和状态如何逐步变化。支持 16 个预设算法、单步执行、自动运行、撤销、执行记录及自定义规则。

## 使用

在手机或电脑浏览器中打开 GitHub Pages 发布的网址，无需登录。选择预设并点击“载入示例”，再使用“单步”或“自动运行”；也可以编辑输入和转移表，点击“应用并重置”后运行。

规则格式为 `当前状态,读入字符,写入字符,移动方向,下一状态`。起始状态为 `q0`，停机状态为 `qa`，空白字符为 `B`；移动方向使用 `L`、`R` 或 `N`。

## 部署与更新

此目录仅包含静态网站。`index.html` 已内嵌样式、程序和校徽，不依赖外部脚本或图片服务。将本目录文件提交到公开仓库，在 GitHub Pages 中选择从 `main` 分支根目录发布即可；`.nojekyll` 用于直接发布静态文件。

更新时，在原项目运行 `node build.js`，再将生成的 `图灵机模拟器.html` 复制为此目录的 `index.html` 并提交。页面中的计算在访问者浏览器内完成，不向服务器提交输入或转移表。
